📲 Install IQC 1.0 System as a Mobile or Desktop App
✅ PWA (Progressive Web App) Ready
This file is pre-configured with a built-in App Icon, Full-Screen Standalone Mode, and Offline Storage.
📱 1. Install on Android / iPhone (Home Screen App)
  • Android (Chrome): Tap the ⋮ (3-dots menu) at the top-right and select Add to Home screen or Install app.
  • iPhone / iPad (Safari): Tap the Share icon (⬆️) at the bottom and select Add to Home Screen. It will open full-screen like a native app.
💻 2. Install as a Windows / Mac Desktop App
  • Host this single HTML file for free on GitHub Pages, Netlify Drop (app.netlify.com/drop), or a local network server.
  • In Chrome or Microsoft Edge, click the Install App icon (⊕) in the address bar to pin it to your Desktop & Taskbar as a standalone window.
📦 3. Convert to Android APK File (.apk)
  • Upload this iqc_incoming_inspection_system.html file to WebIntoApp.com or wrap it with Capacitor / Apache Cordova to generate an installable .apk file for factory tablets and phones.
